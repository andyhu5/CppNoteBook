**C++23：编译期格式字符串检查 + 减小 `std::format` 家族的二进制体积**

这是 C++23 中 `<format>` 库的两个重要改进，主要来自 **P2216R3 "std::format improvements"** 以及相关提案。

---

### 1. **Compile-time format string checks**（编译期格式字符串检查）

**C++20 的问题**：

- `std::format` 的格式字符串在**运行时**才检查。
- 如果格式字符串有错误（类型不匹配、非法说明符等），只有运行时才会抛 `std::format_error`。
- 这对库和大型项目来说非常不友好（难以静态发现错误）。

**C++23 的改进**：

- **编译期检查**（尽可能早发现错误）。
- 如果格式字符串是**字面量**（literal）或**编译期常量**，编译器会在**编译阶段**进行检查。
- 检查内容包括：
  - 格式说明符是否合法（`%d`、`%s` 等）
  - 参数类型与格式说明符是否匹配
  - 动态宽度/精度是否合理
  - 转义字符是否正确等

**示例**：

```cpp
// C++23
std::string s1 = std::format("{:d}", "hello");   // 编译错误！字符串不能用 %d

std::string s2 = std::format("{:10s}", 42);      // 编译错误！整数不能用 %s

// 正确示例
std::string ok = std::format("{:10} - {:04d} - {:.2f}", "text", 42, 3.14159);
```

**好处**：

- 早期发现 Bug（编译时而非运行时）。
- 提升安全性（尤其在库代码中）。
- 更好的 IDE / 静态分析支持。

---

### 2. **Reducing binary code size of std::format() family**（减小二进制体积）

**C++20 的问题**：

- `std::format` 家族（`format`、`format_to`、`vformat` 等）生成的代码体积较大。
- 每个不同的格式字符串或类型组合都会生成大量模板实例，导致**二进制膨胀**（binary bloat）。

**C++23 的改进**：

- **大幅优化模板实例化策略**。
- 使用**类型擦除**（type erasure）和**集中式格式化器**技术。
- 减少重复生成的代码，尤其是当格式字符串包含多种参数类型时。
- 对 `std::format`、`std::print`、`std::vformat` 等函数的实现进行瘦身。

**实际效果**：

- 在典型项目中，`std::format` 相关的代码体积可**减少 30%~70%**（取决于使用场景）。
- 特别对大型项目、游戏、嵌入式等对二进制大小敏感的领域非常友好。
- `std::print` / `std::println`（C++23 新增）也受益于此优化。

---

### 3. 总结对比

| 特性           | C++20                | C++23                                 | 主要收益         |
| -------------- | -------------------- | ------------------------------------- | ---------------- |
| 格式字符串检查 | 运行时检查           | **编译期检查**（字面量时）            | 更早发现错误     |
| 二进制代码体积 | 较大（模板膨胀严重） | **显著减小**（优化实例化 + 类型擦除） | 更小的可执行文件 |
| 编译错误友好度 | 差                   | 大幅提升                              | 更好的开发者体验 |

---

### 4. 额外提示

- **编译器支持**：GCC 13+、Clang 16+、MSVC 19.34+ 已较好支持这些改进。
- **与 `std::print`**：C++23 新增的 `std::print` / `std::println` 也自动受益于这些优化，且默认支持终端颜色等特性。
- **与 Locale**：结合之前的 locale 修复，C++23 的 `std::format` 已经非常成熟。

---

**一句话总结**：

C++23 让 `std::format` **既安全又高效** —— 编译期就能抓住格式错误，同时显著减少了生成的机器码体积，这是 `<format>` 库在 C++23 中最值得关注的两个实用改进。
