在 PowerShell 中设置代理主要有三种方式：**当前会话临时设置、用户级永久设置、Windows 系统代理设置**。

## 1. 当前 PowerShell 会话设置代理（临时）

只对当前 PowerShell 窗口有效：

```powershell
$env:HTTP_PROXY="http://127.0.0.1:7890"
$env:HTTPS_PROXY="http://127.0.0.1:7890"
```

检查：

```powershell
echo $env:HTTP_PROXY
echo $env:HTTPS_PROXY
```

测试：

```powershell
curl https://www.google.com
```

关闭当前窗口后失效。

------

## 2. 永久设置 PowerShell 用户环境变量

写入用户环境变量：

```powershell
[Environment]::SetEnvironmentVariable(
    "HTTP_PROXY",
    "http://127.0.0.1:7890",
    "User"
)

[Environment]::SetEnvironmentVariable(
    "HTTPS_PROXY",
    "http://127.0.0.1:7890",
    "User"
)
```

重新打开 PowerShell：

```powershell
echo $env:HTTP_PROXY
```

删除：

```powershell
[Environment]::SetEnvironmentVariable("HTTP_PROXY",$null,"User")
[Environment]::SetEnvironmentVariable("HTTPS_PROXY",$null,"User")
```

------

## 3. 设置 ALL_PROXY（支持 SOCKS5）

如果代理软件提供 SOCKS5：

例如 Clash / sing-box：

```
127.0.0.1:7891
```

设置：

```powershell
$env:ALL_PROXY="socks5://127.0.0.1:7891"
```

永久：

```powershell
[Environment]::SetEnvironmentVariable(
    "ALL_PROXY",
    "socks5://127.0.0.1:7891",
    "User"
)
```

------

## 4. PowerShell Profile 自动设置

推荐开发环境使用。

查看 profile：

```powershell
$PROFILE
```

创建：

```powershell
New-Item -ItemType File -Path $PROFILE -Force
```

编辑：

```powershell
notepad $PROFILE
```

加入：

```powershell
$env:HTTP_PROXY="http://127.0.0.1:7890"
$env:HTTPS_PROXY="http://127.0.0.1:7890"
$env:ALL_PROXY="socks5://127.0.0.1:7891"
```

以后每次启动 PowerShell 自动生效。

------

## 5. Windows 系统代理（WinHTTP）

查看：

```powershell
netsh winhttp show proxy
```

设置：

```powershell
netsh winhttp set proxy 127.0.0.1:7890
```

恢复：

```powershell
netsh winhttp reset proxy
```

注意：

- `HTTP_PROXY` / `HTTPS_PROXY` 主要影响命令行工具：
  - git
  - curl
  - wget
  - pip
  - npm
  - go
  - cargo
- `netsh winhttp` 主要影响：
  - Windows 服务
  - 系统组件
  - 某些后台程序

------

## 6. Git 单独设置代理

如果用于 GitHub：

```powershell
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
```

查看：

```powershell
git config --global --get http.proxy
```

取消：

```powershell
git config --global --unset http.proxy
git config --global --unset https.proxy
```

------

## 7. WSL Ubuntu 与 PowerShell 代理同步

如果 Windows 使用代理（例如 Clash），WSL 中通常需要：

```bash
export HTTP_PROXY=http://$(grep nameserver /etc/resolv.conf | awk '{print $2}'):7890
export HTTPS_PROXY=$HTTP_PROXY
```

因为 WSL2 默认通过虚拟网卡访问 Windows。

如果你使用 Windows 11 WSL **Mirrored 网络模式**，可以直接：

```bash
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
```

这与你前面提到的 WSL mirrored 网络环境匹配。
