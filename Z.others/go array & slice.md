Go 中数组（array）和切片（slice）是两种不同的类型，区别很大。

## 1. 长度是否固定

**数组**：长度是类型的一部分，编译时固定，不可变。

```go
var a [3]int        // 类型是 [3]int
var b [5]int        // 类型是 [5]int，和 a 是不同的类型！

a = b  // ❌ 编译错误：类型不匹配
```

**切片**：长度可变，是对底层数组的"视图"（引用）。

```go
s := []int{1, 2, 3}   // 类型是 []int
s = append(s, 4)       // ✅ 可以动态增长
```

## 2. 值传递 vs 引用传递

**数组**是值类型，赋值或传参时会**完整拷贝**：

```go
a := [3]int{1, 2, 3}
b := a          // 拷贝了整个数组
b[0] = 100
fmt.Println(a)  // [1 2 3] —— a 没变
fmt.Println(b)  // [100 2 3]
```

**切片**底层是一个结构体，包含指向数组的指针、长度（len）、容量（cap）。拷贝切片只拷贝这个"描述符"，底层数组是共享的：

```go
s := []int{1, 2, 3}
t := s          // 只拷贝了指针/len/cap，底层数组共享
t[0] = 100
fmt.Println(s)  // [100 2 3] —— s 也变了！
fmt.Println(t)  // [100 2 3]
```

## 3. 底层结构

切片本质上是这样一个结构体（简化理解）：

```go
type sliceHeader struct {
    ptr *T   // 指向底层数组的指针
    len int  // 当前长度
    cap int  // 容量（从 ptr 开始到底层数组末尾的长度）
}
```

数组则就是一段连续内存本身，没有这层包装。

## 4. 声明和初始化

```go
// 数组：长度写死或用 [...] 让编译器数
var arr1 [5]int
arr2 := [3]string{"a", "b", "c"}
arr3 := [...]int{1, 2, 3, 4}   // 编译器自动推断长度为4

// 切片：不写长度，或用 make
var s1 []int
s2 := []int{1, 2, 3}
s3 := make([]int, 5)      // len=5, cap=5
s4 := make([]int, 5, 10)  // len=5, cap=10
```

## 5. 函数传参场景对比

```go
func modifyArray(a [3]int) {
    a[0] = 999   // 只改了拷贝，外部不受影响
}

func modifySlice(s []int) {
    s[0] = 999   // 修改的是底层数组，外部会受影响
}

func main() {
    arr := [3]int{1, 2, 3}
    modifyArray(arr)
    fmt.Println(arr)  // [1 2 3]，没变

    s := []int{1, 2, 3}
    modifySlice(s)
    fmt.Println(s)    // [999 2 3]，变了！
}
```

## 6. append 的坑：容量不够会重新分配

这是切片最容易踩坑的地方——当 `append` 超出容量时，Go 会分配一个**新的底层数组**，此时原切片和新切片就不再共享内存了：

```go
s := make([]int, 3, 3)  // len=3, cap=3，已经满了
s2 := s
s2 = append(s2, 4)      // 容量不够，分配新数组
s2[0] = 100
fmt.Println(s)   // 不受影响，因为 s2 底层已经换了新数组
```

但如果容量够用，append 不会重新分配，两者依然共享：

```go
s := make([]int, 3, 10)  // cap 足够
s2 := s
s2 = append(s2, 4)       // 容量够，复用底层数组
s2[0] = 100
fmt.Println(s[0])  // 100 —— 因为共享底层数组
```

## 一张表总结

| 特性      | 数组                                                  | 切片                      |
| --------- | ----------------------------------------------------- | ------------------------- |
| 长度      | 固定，是类型的一部分                                  | 可变                      |
| 赋值/传参 | 值拷贝（整个数组）                                    | 拷贝描述符，共享底层数组  |
| 底层      | 就是内存本身                                          | 指针 + len + cap 的结构体 |
| 可否 nil  | 不可以（零值是全0数组）                               | 可以（零值是 nil）        |
| 常用场景  | 很少直接用，多用于固定大小场景（如哈希值 `[32]byte`） | 日常开发中几乎都用它      |

**实际开发中，切片几乎总是首选**，数组用得较少，主要用在你明确知道大小且不希望被意外修改共享数据的场景。
