### `Repeater` 中常用变量

| 变量        | 含义                 | 你的例子中的值                   |
| ----------- | -------------------- | -------------------------------- |
| `index`     | 当前 delegate 的索引 | 0、1、2                          |
| `modelData` | 当前模型项的数据     | `"Apple"`、`"Peach"`、`"Orange"` |

如果模型不是简单数组，而是 `ListModel`，则不能使用 `modelData`，而是使用角色（role）名称，例如：

```
ListModel {
    ListElement { name: "Apple"; price: 10 }
    ListElement { name: "Peach"; price: 20 }
}

Repeater {
    model: fruitModel

    Text {
        text: name + " : " + price
    }
}
```

这是 `Repeater` 最常见的两种模型使用方式。

### Rectangle Hover Handler ：

```json
                SequentialAnimation {
                    id: flashAnim

                    ColorAnimation {
                        target: rect
                        property: "color"
                        to: rect.flashColor
                        duration: 100
                    }

                    ColorAnimation {
                        target: rect
                        property: "color"
                        to: rect.normalColor
                        duration: 200
                    }


                }


                HoverHandler {
                    acceptedDevices: PointerDevice.Mouse
                    onHoveredChanged: {
                        if (hovered)
                            flashAnim.restart()
                    }
                }
```



`DragHandler` 事件

常用的有：

| 事件                   | 说明                        |
| ---------------------- | --------------------------- |
| `onActiveChanged`      | 开始拖拽/结束拖拽（最常用） |
| `onTranslationChanged` | 拖动位移发生变化            |
| `onCentroidChanged`    | 鼠标（或触点）中心位置变化  |
| `onGrabChanged`        | 抓取状态发生变化            |
| `onCanceled`           | 拖拽被取消                  |
